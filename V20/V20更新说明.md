# 学术组图工具 V20 更新说明

V20 保留 V19 的 GUI、智能网格、非对称布局、矢量 PDF 导出、`.figbox` 和 provenance 能力，新增正式 Agent CLI。

## 1. Agent CLI

入口文件：`agent_cli.py`。

```powershell
python agent_cli.py compose `
  --input "D:\path\to\pdfs" `
  --output "D:\path\to\output" `
  --layout auto `
  --name Figure_1
```

一次运行完成：

1. 扫描和排序输入 PDF、PNG、JPG、TIFF、BMP。
2. 按多页策略生成 panel。
3. 调用 V20 原有布局引擎。
4. 导出 PDF、PNG、TIF 或全部格式。
5. 保存可由 GUI 重新打开的 `.figbox`。
6. 生成布局 JSON、provenance JSON 和预览 PNG。
7. 检查 panel 边界、重叠、PDF 页数和 FigBox 素材数量。

成功时日志包含：

```text
V20_VALIDATION=PASS
```

## 2. 布局参数

- `auto`
- `4x4` 或其他行列组合
- `columns:2+1`
- `rows:2+1`
- `2+1`，默认解释为列模板
- `左二右一`、`上二下一` 等 GUI 同义布局

支持全部三种智能网格行为：

- `equal-height`：等高填充。
- `uniform-scale`：统一比例填充。
- `no-scale`：仅摆放，不缩放。

支持 `--span-left`、`--span-width`、`--top`，等价于 GUI 画线指定布局位置和宽度。

## 3. 多页 PDF

- `first`：只取第 1 页，默认。
- `split`：将每页作为独立 panel，并保留原文件与页码记录。
- `error`：发现多页 PDF 即停止，避免遗漏。

## 4. 输出保护

默认不覆盖同名结果。使用 `--overwrite` 时，旧结果移动到输出目录的 `.Trash`，不会直接删除。

## 5. 版本隔离

- GUI 入口改为 `run_v20.py`。
- 用户设置保存为 `%USERPROFILE%/.figbox/settings_v20.json`。
- `.figbox` 项目版本为 `20.0`。
- V19 目录和设置保持不变。

## 6. 测试

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

测试覆盖继承布局、V20 设置、全部智能网格、严格输入顺序、多页拆分、图片导入、项目编辑、边界持久化、导出和自动验证。

## 7. 项目编辑命令

- `inspect`：检查项目。
- `relayout`：重新布局全部或指定 panel。
- `edit`：缩放、等宽、等高、六种对齐、水平/垂直均分、定间距、旋转、移动、修改尺寸、删除和标签级联。
- `boundary`：四方向扩展、紧缩和恢复。
- `canvas`：画布、边距、间距、DPI、标签和裁剪设置。
- `export`：从现有项目导出所有格式并验证。
- `preferences`：管理 GUI 持久化默认设置。

GUI 中标签字号、颜色、加粗和显示状态现在会真实传入 PDF、PNG、TIF 导出。

## 8. 边界修改持久化

修复边界扩展/紧缩派生 PDF 未嵌入 `.figbox` 的问题。V20 会同时嵌入原始素材与派生素材，项目移动到其他电脑后仍可重现边界修改。

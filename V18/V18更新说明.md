# 学术组图工具 V18 更新说明（Smart Grid · Proportional Fill Edition）

基于 V17（FigBox 容器版）。核心目标：**把组图里最耗时的"反复缩放对齐铺满画布"自动化，
同时保留每张图自己的比例（不强行等高）**。

## 启动方式

```bat
python run_v18.py            # 默认 light 主题
python run_v18.py dark       # 暗色主题
双击 启动V18.bat
```

完全兼容 V17 的 `.figbox` / `.figproj` 项目文件。

---

## 新功能

### 1. 🔳 智能网格（核心，等高填充到画线宽度）
选中若干图后点"智能网格"，选择 **行×列**（如 1×4、2×2、3×2…），
并有一个复选框 **「等高填充宽度」（默认勾选）**：

- **勾选（默认）**：点 OK 后鼠标变成画线工具，在画布上**拖一条横线**——
  线长即填充宽度（线本身不留在图上）。选中图被缩放到**同一高度**正好铺满该宽度。
  → 等高的图永远保持等高（修复了之前多行系数不一致、等高图变不等高的问题）；
  不等高的图会被统一拉到同一高度，各自宽高比保留。
  横线的左端=起始 x、纵向位置=该行顶部，等于一次手势同时定"多宽、放哪儿"。
  **直接单击（不拖动）= 用整幅画布可用宽度填充**，省去画线；右键取消。
- **取消勾选**：等同 V17 原版——仅把图按 行×列 摆好，**不改变任何图片大小**。

多行（如 2×2）时，每一行各自等高填满画线宽度；想把左边已摆好的图也算进来，一起选中即可。

### 2. 拖图落在拖放位置
把 PDF/图片拖进画布时，图的**中心落在你松手的位置**，不再自动跳到正中央；
一次拖入多张时依次轻微错开避免完全重叠。

### 3. 标签级联联动
标签顺序即图片顺序。把某图标签改成已存在的标签（如 C→B）时，
其余标签**自动顺延**（原 B C D → C D E），始终保持 A、B、C… 连续。

### 4. 导出默认 1000 DPI + 光栅导出提速
- 导出 DPI 默认改为 **1000**（出版级），仍可在下拉框选 72–1200。屏幕预览仍用低 DPI。
- PNG/TIF 导出改为**按目标像素尺寸直接渲染**，不再先过度渲染再缩小。
  对点很多的矢量图（如单细胞 UMAP）可明显提速，且最终分辨率不变、不损失清晰度。
- **点很多的矢量图建议直接导出 PDF**：PDF 导出是矢量嵌入（`show_pdf_page`），
  不做光栅化——既最快又无限清晰、文件还小，投稿矢量图首选。

### 5. 导入初始铺排
导入后用**全局统一缩放 + 按宽度换行**给出整齐的初始铺排（保留各图相对大小），
供后续用"智能网格"精修。

## 删除 / 暂缓

- **删除** 7 个低效自动排版：规则网格、紧凑、黄金分割、瀑布流、智能分组、
  自适应权重、🤖 AI 智能布局。对齐、分布、批量缩放等手动工具全部保留。
- **暂缓** 一键全自动排版：等"智能网格"用顺、确认手感后，再在它之上设计。

## 算法说明（第一性）

**等高填充**（勾选时）——把若干图缩放到同一高度 `h`、铺满宽度 `W`：

> 各图宽高比 `a_i = 宽/高`，要求等高 `h` 且总宽含间距 = `W`：
> `Σ(a_i·h) + (k−1)·gap = W` ⇒ `h = (W − (k−1)·gap) / Σa_i`。
> 输出全部等高、各自比例保留、总宽恰好 = `W`。等高输入永远保持等高。
> `W` 来自鼠标画的横线；单击则取整幅画布可用宽度。

**等比铺满**（备用原语 `uniform_fill`）——乘同一系数填满宽度、保留高度差异：
> `s = (span − (k−1)·gap) / Σ宽度`，相对大小与各自比例完整保留，高度各不相同。

逻辑测试见 `tests/test_layout_v18.py`。

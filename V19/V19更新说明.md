# 学术组图工具 V19 更新说明（Smart Grid · Proportional Fill Edition）

基于 V18（FigBox 版本）。核心目标：**把常用排版默认值做成可保存设置，
并把智能网格扩展到论文中常见的非对称版式**。

## 启动方式

```bat
python run_v19.py            # 默认 light 主题
python run_v19.py dark       # 暗色主题
双击 启动V19.bat
```

完全兼容 V18 的 `.figbox` / `.figproj` 项目文件。

---

## 新功能

### 1. 默认边距改为 5mm
V19 新建项目 / 新建画布默认边距从 **10mm** 改为 **5mm**。
打开旧 `.figbox` / `.figproj` 时仍保留旧项目里保存的边距，不会破坏已排好的版面。

### 2. 持久化设置
新增 **设置** 菜单和工具栏按钮。可以保存以下默认值，下次启动后继续生效：

- 画布预设、宽度、高度
- 边距、图间距、网格大小
- DPI、导出格式、自动裁剪
- 标签字号、颜色、加粗、显示状态、标签距离
- 网格吸附、辅助线、标尺
- 自动备份开关和备份间隔

设置文件保存在用户目录下的 `.figbox/settings_v19.json`。

### 3. 智能网格（行列 + 非对称模板）
选中若干图后点"智能网格"，选择 **行×列**（如 1×4、2×2、3×2…），
并有一个复选框 **「等高填充宽度」（默认勾选）**：

- **勾选（默认）**：点 OK 后鼠标变成画线工具，在画布上**拖一条横线**——
  线长即填充宽度（线本身不留在图上）。选中图被缩放到**同一高度**正好铺满该宽度。
  → 等高的图永远保持等高（修复了之前多行系数不一致、等高图变不等高的问题）；
  不等高的图会被统一拉到同一高度，各自宽高比保留。
  横线的左端=起始 x、纵向位置=该行顶部，等于一次手势同时定"多宽、放哪儿"。
  **直接单击（不拖动）= 用当前画布可用宽度填充**，横版按横版宽度，竖版按竖版宽度；右键取消。
- **取消勾选**：等同 V18 原版——仅把图按 行×列 摆好，**不改变任何图片大小**。

多行（如 2×2）时，每一行各自等高填满画线宽度；想把左边已摆好的图也算进来，一起选中即可。

新增左右非对称模板：

- 3 张图：左二右一、左一右二
- 4 张图：左三右一、左一右三
- 5 张图：左三右二、左二右三
- 6 张图：左四右二、左二右四、三列各二
- 自定义模板：例如 `2+1`、`3+1`、`1+2`、`2+2+2`

例如 `左二右一` 表示 A/B 放左侧上下，C 放右侧大图位置；左右总高度自动对齐，整体铺满指定宽度。

新增上下非对称模板：

- 3 张图：上二下一、上一下二
- 4 张图：上三下一、上一下三
- 5 张图：上三下二、上二下三
- 6 张图：上四下二、上二下四、上下各三

例如 `上二下一` 表示 A/B 放上排，C 放下排大图位置；每一排都自动铺满同一画布宽度。

### 4. 横版画布单击填充修复
智能网格进入画线模式后，如果只单击不拖线，V19 会使用**当前画布真实宽度 - 左右边距**。
该逻辑对 A4 横版、A4 竖版、多画布和打开旧项目后的画布都一致。

### 5. 导出 provenance JSON
一键导出和普通导出不再生成 `_info.md`，统一生成结构化 JSON：

- 每张原始图旁边可放置 `<stem>.provenance.json`
- 组图导出时生成 `<export_base>_provenance.json`
- JSON 记录 panel 标签、文件名、原始路径、排版位置和来源代码信息

### 6. 导出画布自动包住越界图片
导出 PDF、TIF、PNG 时，如果有图片超出画布范围，V19 会自动计算所有图片的包围盒：

- 勾选自动裁剪：导出画布会裁到图片包围盒，去掉 A4 空白
- 不勾选自动裁剪：保留原画布大小
- 左侧或顶部越界：导出副本会整体平移回画布内
- 右侧或底部越界：导出画布会自动扩大
- 当前编辑画布上的图片位置不会被改动

这样可以保证导出文件中所有图片都在画布内，不会因为越界被裁掉。

### 7. 图源 provenance 自动适配
如果图片同目录下存在 `<stem>.provenance.json`，V19 导入图片时会自动读取：

- 文件列表中显示 `provenance` 标记
- `.figbox` 保存时保留 provenance 信息
- 导出组图时生成 `<export_base>_provenance.json`

组合 provenance 会把每个 panel 的标签、原始图路径、排版位置和对应 sidecar 信息关联起来，方便后续大模型写结果报告。

旧项目可用 `tools/generate_figure_provenance.R` 根据已有 R/Python 代码批量生成 sidecar JSON。

## 算法说明（第一性）

**等高填充**（普通行列）——把若干图缩放到同一高度 `h`、铺满宽度 `W`：

> 各图宽高比 `a_i = 宽/高`，要求等高 `h` 且总宽含间距 = `W`：
> `Σ(a_i·h) + (k−1)·gap = W` ⇒ `h = (W − (k−1)·gap) / Σa_i`。
> 输出全部等高、各自比例保留、总宽恰好 = `W`。等高输入永远保持等高。
> `W` 来自鼠标画的横线；单击则取整幅画布可用宽度。

**等比铺满**（备用原语 `uniform_fill`）——乘同一系数填满宽度、保留高度差异：
> `s = (span − (k−1)·gap) / Σ宽度`，相对大小与各自比例完整保留，高度各不相同。

**非对称列模板**——每一列有固定张数，例如 `2+1`。
各列缩放到相同总高度，并让所有列的总宽度加列间距正好等于目标宽度。

**导出包围盒**——导出时根据所有图片的 `x/y/width/height` 计算边界。
若左上越界，则只平移导出副本；若右下越界，则扩大导出画布。

**组合 provenance**——组图导出时读取每个 panel 的 sidecar JSON，并生成一个组图级 JSON。
它不重新推断代码，只把已经存在的 provenance 与 panel 标签和排版信息绑定。

逻辑测试见 `tests/test_layout_v19.py`。
